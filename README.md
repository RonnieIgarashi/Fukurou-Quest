# フクロウクエスト（プロトタイプ）

ドット絵の箱庭生活シミュレーション。旅人とミミズクのモクちゃんが海辺の村で暮らしながら、100日目に訪れるドラゴンに備える。

- 設計：`docs/DESIGN.md`
- 素材の差し込み：`public/assets/README.md`

```bash
npm install
npm run build
npm run serve   # http://localhost:8766/
npm test
```

操作：矢印キーで歩く（Shift で走る）／Z・Enter で調べる・決定・建物に入る／X でもどる・メニュー／Esc でメニュー／Q で引いて見る（ふだん→少し引き→村全体）

メニューの「もじ」で、ひらがな表示に切り替えられる。
