# フクロウクエスト — 設計書（プロトタイプ v0.1）

正式な企画・仕様は Notion「フクロウクエスト — 開発仕様書」（v0.2.2 時点）。この文書は、それをどう作ったか・何を仮に決めたかを書く。

## 1. プロトタイプの範囲

| 入っている | 入っていない（今後） |
|---|---|
| タイトル、日記帳（セーブ枠3つ）、名前入力（カタカナ6文字まで） | 森・荒野・ビーチ・山・洞窟の5エリア |
| ゲーム内時計（1時間＝実1分）、日数、昼夜の光 | 牛、食糧・飲み水、クラフト、要塞 |
| タスクによる時間スキップ（耕す・種まき・収穫・休む・寝る） | 竜の言葉、情報収集、100日目の分岐 |

対象ブラウザは PC の Chrome。将来は PC の Chrome・Brave・Firefox・Edge と iPhone・Android。

## 2. 技術の構成

ペンギンサバイバルと同じ型。TypeScript（依存は typescript のみ）＋ Canvas 2D。ビルドは `tsc`、テストは `node:test`。

```
src/
  core/            DOM に依存しない（テストできる）
    params.ts      調整値（【確定】と【仮】を明記）
    clock.ts       時計（通算分1つで持つ）
    sim.ts         時間を進める advance()。リアルタイムもタスクもここを通る
    tasks.ts       タスク（行動）の選択肢と実行
    state.ts       ゲーム状態（＝セーブデータの中身）
    map.ts         村の地形・調べられる場所
    story.ts       台本（台詞はすべて仮）とムービーの差し込み先
    names.ts       名前の検証・文字盤
    save/          セーブの窓口（後述）
  view/            描画（ドット絵、地形、光、画面出力、素材）
  input.ts         キー入力（スマホのボタンからも呼べる形）
  main.ts          画面の切り替えとループ
public/assets/     顔画像・ムービーを置く場所（README あり）
```

### 時間の原則（仕様書 16章）

- 時刻は「1日目 0:00 からの通算分」の1つの数だけで持つ。
- リアルタイムの進行も、タスクの時間スキップも、必ず `advance()` を通す。正時をまたぐたびに判定（朝の畑・夜のイベント・自動セーブ）を行うので、まとめて進めても1分ずつ進めても結果は同じ（テストで確認）。
- 会話・メニュー・タスク中のアニメーション、タブを閉じている間は進まない。

## 3. 画面とビジュアル

- 内部解像度 **384×216（16:9）**。ウィンドウに収まる最大の整数倍で拡大する（1920×1080 なら5倍）。
- ドット絵は内部解像度で描いて拡大。**文字と顔画像は拡大後の高解像度で描く**ので、文字はくっきり、顔画像は滑らかに出る。フォントは DotGothic16（Google Fonts）。
- ペンギンサバイバル（256×224）より一段リッチにするため、次を入れた。
  - 時刻の光：夜明け・夕焼け・夜の色を時刻で補間して乗算。夜は窓と炉が灯り、ホタルが飛ぶ
  - 周辺減光、足元の影、ブロック状の木（上面が明るい立方体）、揺れる水面
  - キャラクターは形を塗ってから輪郭線を自動で付け、左上からの光で陰影を付ける
- 主人公は 16×24、仲間は 16×16。

### 素材の差し込み口

ファイルを置くだけで使われ、無ければ代わりの表示で進む（`public/assets/README.md`）。

| 種類 | 置き場所 | 無いとき |
|---|---|---|
| 顔画像 | `assets/portraits/player.png`・`moku.png`・`momo.png` | ドット絵を拡大して表示 |
| ムービー | `assets/movies/opening.mp4`・`dragon-arrival.mp4` | 「MOVIE（未設定）」の札を出して先へ |

## 4. セーブと将来の DB

ゲームは `SaveStore`（`src/core/save/store.ts`）だけを使い、保存先を知らない。

```ts
interface SaveStore {
  list(): Promise<SaveSummary[]>;
  load(slotId: string): Promise<SaveFile | null>;
  save(file: SaveFile): Promise<void>;
  remove(slotId: string): Promise<void>;
}
```

- 今は `LocalSaveStore`（ブラウザの localStorage）。使えない環境では閉じるまでの一時保存になる。
- セーブデータは `SaveFile = { schema, slotId, ownerId, createdAt, updatedAt, game }` の JSON 1件。`schema` を上げたら `migrate()` に変換を足す。欠けた項目は新規ゲームの値で補う。
- 自動セーブ：ゲーム内1時間ごと、寝たとき、タブを隠した・閉じたとき。手動：小屋の扉「日記をつける」、メニュー「セーブ」。

### 友人に公開するとき（案）

`RemoteSaveStore` を同じ形で作り、`main.ts` の1行を差し替える。費用をかけない候補は Cloudflare Workers ＋ D1（無料枠。上限は導入時に確認）。

```
saves(owner_id TEXT, slot_id TEXT, player_name TEXT, data TEXT, updated_at TEXT,
      PRIMARY KEY (owner_id, slot_id))
GET    /saves            → 一覧
GET    /saves/:slot      → 1件
PUT    /saves/:slot      → 保存（updated_at が古ければ 409 で上書きを防ぐ）
DELETE /saves/:slot
```

利用者の識別（ログインの方式）は未決定。決めるまでは `ownerId` を null のまま持つ。

## 5. 仮の値（プロトタイプのために置いたもの）

`src/core/params.ts` に【仮】として集めてある。仕様が決まったら、ここを直す。

| 項目 | 仮の値 | 理由・メモ |
|---|---|---|
| 深夜の強制睡眠 | 2:00 を過ぎると眠り、6:00 に小屋の前で目覚める | 起きたまま夜が終わらないようにするため |
| 寝られる時間 | 18:00 以降、または深夜 | 昼に寝て1日を飛ばすのを防ぐ |
| タスクの所要時間 | 耕す60分・種まき20分・収穫20分・炉10分・休む60分 | |
| 作物 | 豆3日で3つ、麦5日で4つ | 成長の速さの順（豆＞麦＞リンゴ）は確定 |
| 畑のマナ | 1区画が毎朝、地・水・火・風を1つずつ使う。どれか欠けるとその朝は育たない | 仕様の「均等に・不足で止まる」を最小の形にした |
| 炉 | 白のマナ1つが6時間で火のマナ1つに。最大4つ。燃料は不要 | 燃料の要否は未決定 |
| 初期の持ち物 | 豆の種4・麦の種2、マナ 白8・地6・水6・風6・火0 | 村から出られないプロトタイプで、畑を試せる量 |
| ももっちゅりんの登場 | 3日目 9:00 | 仕様の章立て案「1〜15日」の範囲 |
| ももっちゅりんが眠る時間 | 3:00〜9:00 | 「朝に弱い」 |
| 日記帳の数 | 3 | |
| 台詞 | すべて | 正式な台本は今後 |
| モクちゃん・ももっちゅりんの絵 | 仕様書の文章から起こしたもの | 正式な絵に差し替える |

## 6. 100日目の判定（提案。未確定）

仕様書 13章の5つの結末を、整合のとれる数値で判定する案。Ronnie の判断待ち。

| 値 | 意味 | 増える・減る |
|---|---|---|
| 竜語の理解 L（0〜100） | 竜の言葉がどれだけ分かるか | 6か所の手掛かり（ボトルの文書・手帳・精霊・人面牛・壁画と古文書・古い墓）で増える |
| 竜の警戒 H（0〜100） | ドラゴンがどれだけ刺激されているか | 主人公の攻撃、ビーチに放した牛、兵器の配備で増える。リンゴを置くと下がる |
| 防衛力 D | 戦いになったときの強さ | 要塞の壁・兵器・仲間の牛（攻撃／防御レベル）の合計 |
| 竜の強さ S | 来訪する個体ごとに固定 | — |

| 順 | 結末 | 条件（案） |
|---|---|---|
| 1 | 交渉・交易成立 | L が基準以上、H が低い、交渉を選ぶ |
| 2 | 何も起きずにやり過ごす | H が低く、誰も攻撃しない |
| 3 | 準備十分で圧勝 | 戦いになり、D が S を大きく上回る（村・森の被害は大） |
| 4 | 準備不足で辛勝 | 戦いになり、D がわずかに S を上回る（村は壊滅的） |
| 5 | 敗北 | 戦いになり、D が S に届かない |
