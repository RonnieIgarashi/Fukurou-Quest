# フクロウクエスト — 設計書（プロトタイプ v0.3）

正式な企画・仕様は Notion「フクロウクエスト — 開発仕様書」（v0.2.4 時点）。この文書は、それをどう作ったか・何を仮に決めたかを書く。

## 1. プロトタイプの範囲

| 入っている | 入っていない（今後） |
|---|---|
| タイトル、日記帳（セーブ枠3つ）、名前入力（カタカナ6文字まで） | 森・荒野・ビーチ・山・洞窟の5エリア |
| ゲーム内時計（1時間＝実1分）、日数、昼夜の光 | 牛、食糧・飲み水、クラフト、要塞 |
| タスクによる時間スキップ（耕す・種まき・収穫・休む・寝る） | 竜の言葉、情報収集、100日目の分岐 |
| 村エリア（水彩の一枚絵）：小屋・鍛冶小屋（炉）・畑6区画・噴水・浜辺・立て札 | 効果音・BGM |
| モクちゃん（夜に眠る）、ももっちゅりん（3日目に登場、朝に眠る） | スマホ操作（設計だけ対応済み） |

| 顔画像・ムービーの差し込み口 | |

対象ブラウザは PC の Chrome。将来は PC の Chrome・Brave・Firefox・Edge と iPhone・Android。

## 2. 技術の構成

ペンギンサバイバルと同じ型。TypeScript（依存は typescript のみ）＋ Canvas 2D。ビルドは `tsc`、テストは `node:test`。

```
src/
  core/            DOM に依存しない（テストできる）
    params.ts      調整値（【確定】と【仮】を明記）
    clock.ts       時計（通算分1つで持つ）
    sim.ts         時間を進める advance()。リアルタイムもタスクもここを通る
    tasks.ts       タスク（行動）の選択肢と実行
    state.ts       ゲーム状態（＝セーブデータの中身）
    map.ts         村の歩ける範囲・通れない物・調べられる場所・手前に来る物（絵の座標の多角形）
    story.ts       台本（台詞はすべて仮）とムービーの差し込み先
    names.ts       名前の検証・文字盤
    save/          セーブの窓口（後述）
  view/            描画（背景の絵、ドット絵、光、画面出力、素材）
  input.ts         キー入力（スマホのボタンからも呼べる形）
  main.ts          画面の切り替えとループ
public/assets/     背景の絵・顔画像・ムービーを置く場所（README あり）
docs/concept/      Ronnie のイメージ絵（村・ウシ・ドラゴン・モクちゃんとももっちゅりん）
```

### 時間の原則（仕様書 16章）

- 時刻は「1日目 0:00 からの通算分」の1つの数だけで持つ。
- リアルタイムの進行も、タスクの時間スキップも、必ず `advance()` を通す。正時をまたぐたびに判定（朝の畑・夜のイベント・自動セーブ）を行うので、まとめて進めても1分ずつ進めても結果は同じ（テストで確認）。
- 会話・メニュー・タスク中のアニメーション、タブを閉じている間は進まない。

## 3. 画面とビジュアル（2026-11-16 Ronnie 決定：手描き背景＋高解像度ドット）

レジェンドオブマナと同じ作り。**水彩の一枚絵を背景にして、その上でドット絵のキャラクターを動かす。**

- フィールドの内部解像度は **640×360（16:9）**。ウィンドウに収まる最大の整数倍で拡大する（1920×1080 なら3倍、1280×720 なら2倍）。
- 村の背景は `docs/concept/village.jpg`（2000×1493）をそのまま使う（`public/assets/maps/village.jpg`）。絵の1px＝ゲームの1px。画面に映るのは絵の約1/9。
- 歩ける範囲・通れない物・調べられる場所は、絵から測った多角形で `src/core/map.ts` に持つ。
- 建物・木・噴水は、人物がその奥にいるときだけ、絵の切り抜きを人物の上に重ねて隠す（`OCCLUDERS`）。輪郭にぴったり沿わせないと、そばを歩く人物まで消える。
- 東の家を鍛冶小屋（炉）にした。夜は窓が灯り、炉が動いていると窓が赤く光る。
- 畑は絵の3つの畝を上下に分けて6区画。絵に描かれた作物の上に土のドット絵を重ね、その上に作物を描く。
- メニュー・会話の枠は 384×216 の座標で描き、出力の大きさに合わせて拡大する。文字と顔画像は出力の解像度で描くので、くっきり・滑らかに出る。フォントは DotGothic16（Google Fonts）。
- 時刻の光（夜明け・夕焼け・夜の色の乗算）、夜の窓の灯り、ホタル、周辺減光は前の版から引き継いだ。
- 主人公は 32×48、モクちゃん・ももっちゅりんは 32×32 のドット絵。モクちゃんたちは `docs/concept/moku-momo.jpg` に合わせた。

**新しいエリアを足すとき**：背景の絵を1枚用意し（村と同じくらいの縮尺。人の背丈＝扉の高さ≒45px）、`map.ts` と同じ形で歩ける範囲などを測って書く。


## 3b. v0.3 の変更（2026-11-16 Ronnie の指摘を反映）

- **描き方**：フィールドを出力の解像度で直接描くようにした（背景の絵はなめらかに拡大）。映す範囲を 800×450 に広げて俯瞰ぎみに。
- **キャラ**：1.25倍で描く（主人公は約40×60）。ドット絵は4倍に拡大してから縮めて描き、紙のムラを薄く重ね、輪郭線を背景の墨線と同じ焦げ茶に、色を水彩寄りに落ち着かせた。
- **畑**：ドットの四角をやめ、やわらかい塗りと線で描く。作物も筆で描いたような葉に。
- **歩く速さ**：140px／秒。Shift を押しながらで2倍（280px／秒）で走る。
- **木の後ろ**：手前に重ねる切り抜きの縁をぼかし、奥にいる人物が境目に近いほど薄くして、前後の切り替わりをなめらかにした。
- **背景の加工**：`tools/prepare_village.py` が `docs/concept/village.jpg` から `public/assets/maps/village.jpg` を作る。荒野のサボテンを消し、牧場のウシ2頭を切り抜いて `public/assets/sprites/cow1.png`・`cow2.png` にした（背景からは消す）。
- **ウシ**：牧場の中を歩いたり止まったりする（表示だけの動き。セーブしない）。
- **水**：川の流れ、橋の下の滝と滝つぼの泡、波打ち際の寄せては返す波と海のきらめき、噴水の水しぶきと波紋を動かす。
- **建物に入る**：小屋と鍛冶小屋に入れる。寝るのは小屋の中のベッド、日記（セーブ）は机、炉は鍛冶小屋の中。朝は小屋の中で目覚める。室内は仮の絵（`src/view/interior.ts`）で、絵ができたら `map.ts` の `image` に置けば差し替わる。丸太小屋と塔は「室内の絵ができたら入れる」と表示。
- **調べられる物**：慰霊碑・森の入口（慰霊碑のすぐ左の木の立て札）・荒野の立て札・古い荷車・噴水・ベンチ・牧場のウシ・丸太小屋・川・海、室内の窓・止まり木・金床・薪の山。説明は `src/core/story.ts` の `LOOK`。
- **会話**：話し手の顔を文の左に出す（レジェンドオブマナ風）。モクちゃん・ももっちゅりんの顔は、イメージ絵から切り出した仮の顔画像（`public/assets/portraits/`）。正式な顔画像が届いたら差し替える。
- **仲間**：ずっとはついてこない。起きている間は小屋のまわりを止まったり動いたりし、眠る時間は小屋の中の寝床へ。
- **モクちゃんの口癖**：「ホウ」は使わない。うなずくときの「ホウホウ、」だけは可。
- **ひらがなモード**：タイトルとメニューの「もじ」で、漢字をひらがなに切り替える（端末ごとに記憶）。読みの辞書は `src/core/kana.ts`。画面に出る文に辞書にない漢字が残ると、テストが知らせる。
- **マナの表示**：丸い玉に。正式版ではステータス画面で見る（常時表示しない）。プロトタイプは今のまま画面右上に出す。
- **村の配置の訂正**：森の入口は村の右奥、慰霊碑（100年前にドラゴンとの戦いで亡くなった人たちの墓）のすぐ左の立て札。東の矢印の立て札は荒野の入口。噴水の右横はベンチ。

## 4. セーブと将来の DB

ゲームは `SaveStore`（`src/core/save/store.ts`）だけを使い、保存先を知らない。

```ts
interface SaveStore {
  list(): Promise<SaveSummary[]>;
  load(slotId: string): Promise<SaveFile | null>;
  save(file: SaveFile): Promise<void>;
  remove(slotId: string): Promise<void>;
}
```

- 今は `LocalSaveStore`（ブラウザの localStorage）。使えない環境では閉じるまでの一時保存になる。
- セーブデータは `SaveFile = { schema, slotId, ownerId, createdAt, updatedAt, game }` の JSON 1件。`schema` を上げたら `migrate()` に変換を足す。欠けた項目は新規ゲームの値で補う。
- 自動セーブ：ゲーム内1時間ごと、寝たとき、タブを隠した・閉じたとき。手動：小屋の扉「日記をつける」、メニュー「セーブ」。

### 友人に公開するとき（案）

`RemoteSaveStore` を同じ形で作り、`main.ts` の1行を差し替える。費用をかけない候補は Cloudflare Workers ＋ D1（無料枠。上限は導入時に確認）。

```
saves(owner_id TEXT, slot_id TEXT, player_name TEXT, data TEXT, updated_at TEXT,
      PRIMARY KEY (owner_id, slot_id))
GET    /saves            → 一覧
GET    /saves/:slot      → 1件
PUT    /saves/:slot      → 保存（updated_at が古ければ 409 で上書きを防ぐ）
DELETE /saves/:slot
```

利用者の識別（ログインの方式）は未決定。決めるまでは `ownerId` を null のまま持つ。

## 6. 100日目のドラゴン襲来（2026-11-16 Ronnie 決定）

### 流れ

1. ドラゴンが来て、竜語で吠える（話しかけてくる）。
2. 竜語の習熟度に応じて、吠え声が部分的に分かる。
   例：習熟度 0「ゴアアアア」→ 上がると「ぬしら…ゴアゴア…して…グガガガ…平和を…ゴゴゴ」
3. 選択肢：
   - **話を聞いてみる**：竜語の習熟度が 1 以上で出る。話を聞いたあとで攻撃して戦うこともできる
   - **攻撃する**：戦闘へ
   - **隠れる**：何もしない
4. 竜語が使えれば、10回ほどのやり取り（選択肢）を経て、交渉成立・戦闘・やり過ごしのどれに進むかを自分で考えて選べる。

### 結末

| 結末 | 条件 |
|---|---|
| 交渉成立（交易） | 竜語でのやり取りを経て、交渉がまとまる |
| やり過ごす | 牛を手なずけ、攻撃せず、話もせずに隠れている → ドラゴンは飛び去る |
| 戦闘で勝利 | 要塞化レベル・武器防具レベル・戦闘用の牛の総合値で勝敗が決まる |
| 戦闘で敗北 | 同上 |
| ホワイトドラゴン | **絶対に倒せない。** 戦闘で勝っても村は壊滅し、白いドラゴンは飛び去る |

- ドラゴンの幼獣という設定は取りやめ（ストーリーが複雑になりすぎるため）。
- ドラゴンのイメージ絵は `docs/concept/dragons.jpg`（6体）。

### 未決定

- 来るドラゴンの決め方（6体から毎回ランダムか、行動で決まるか）
- 竜語の習熟度の幅（何段階か）と、10回のやり取りに参加できる習熟度の目安
- 「牛を手なずけて」の具体的な条件（何頭・どの牛か）
- 戦闘の総合値の計算式と、勝ち負けの境目

## 6b. 炉の燃料・ウシの落とし物（2026-11-16 Ronnie 決定）

- 炉で白のマナを火に変えるには、**薪などの燃料が要る。**
- 初期のマナ（引っ越しの荷物）は正式版でも残す。

| ウシ | 倒すと落とすもの |
|---|---|
| 黒ウシ | 皮・肉・骨 |
| 白ウシ | 肉・骨 |
| 赤毛ウシ | 骨・毛・肉 |
| 栗毛ウシ | 肉・骨 |

- 倒すとその場に落ち、拾える。拾わないと消える：肉は3時間、毛は1日、骨は2日。
- 肉は食べられる。毛と皮は燃料にもなる。骨は武器の錬成にだけ使う。
- 灰色ウシ・人面ウシの落とし物は未定（人面ウシは仲間にならず好感度のみなので、倒せない想定でよいか確認したい）。

## 8. 動かし方

```bash
npm install
npm run build
npm run serve   # http://localhost:8766/
npm test
```

開発中は、ブラウザのコンソールから `fq.advance(分)` で時間を進められる（`fq.game` で状態を見られる）。
